# AgriGuard — Hardware Communication Protocol Specification

This document defines the structured communication protocol between the Laptop (FastAPI Backend) and the physical ESP32 Hardware Controller over local Wi-Fi.

---

## 1. Transport Mechanisms

- **REST (HTTP Port 80):** High-reliability command dispatch, parameter configuration, and diagnostic queries.
- **WebSocket (Port 81 or `/ws`):** Bi-directional high-frequency live telemetry streaming (10 Hz) and instant asynchronous fault reporting.

---

## 2. Command Schema (Laptop → ESP32)

Every command sent to the ESP32 must be valid JSON containing a unique `command_id` and strict parameters.

### 2.1 Motor Movement (`move`)

```json
{
  "command_id": "CMD-MOVE-9F81",
  "type": "move",
  "direction": "forward",
  "speed": 140,
  "duration_ms": 1000
}
```

- `direction`: `"forward"`, `"backward"`, `"left"`, `"right"`, `"stop"`
- `speed`: Integer `0` to `255` (PWM duty cycle)
- `duration_ms`: Optional pulse duration (0 = continuous until stopped or watchdog timeout)

### 2.2 Precision Spray Actuation (`spray`)

**SAFETY RULE:** Spray commands must contain a signed `approval_token` generated by the backend only after explicit farmer confirmation.

```json
{
  "command_id": "CMD-SPRAY-4A12",
  "type": "spray",
  "duration_ms": 2500,
  "approval_token": "FARMER-AUTH-9201A-EXP1727500000"
}
```

- `duration_ms`: Clamped between `500` ms and `6000` ms.
- If `approval_token` is missing or invalid: ESP32 rejects with HTTP 401 and does NOT energize the pump or solenoid.

### 2.3 Emergency Stop (`estop`)

```json
{
  "command_id": "CMD-ESTOP-0001",
  "type": "estop"
}
```

- Instantly trips hardware fail-safe: stops all PWM channels, cuts pump relay, closes solenoid valve, and sounds continuous buzzer alarm.

---

## 3. Command Acknowledgment (ESP32 → Laptop)

Every command response returns deterministic status:

```json
{
  "command_id": "CMD-SPRAY-4A12",
  "accepted": true,
  "executed": true,
  "timestamp_ms": 149204,
  "hardware_status": {
    "motors": "STOPPED",
    "pump": "ACTIVE",
    "valve": "OPEN",
    "estop_active": false
  },
  "error_code": null,
  "message": "Precision spray initiated for 2500ms"
}
```

### Disconnected Sensor Reporting (Strict Rule 4)

If a sensor fails or is unplugged, the telemetry honestly flags the failure rather than returning zeros or synthetic values:

```json
"npk": {
  "status": "DISCONNECTED",
  "error": "RS485 Modbus timeout: Slave ID 1 not responding",
  "nitrogen_mg_kg": null,
  "phosphorus_mg_kg": null,
  "potassium_mg_kg": null
}
```
